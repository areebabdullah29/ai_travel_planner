# AI‑Powered Travel Buddy ✈️

### Smart Travel Recommendation & Planning Web App using Artificial Intelligence

------------------------------------------------------------------------

## 📌 Project Domain

**Artificial Intelligence, Web Development**

------------------------------------------------------------------------

## 📖 Abstract

AI‑Powered Travel Buddy is an intelligent web-based travel planning
system that generates personalized trips using Artificial Intelligence.

The platform analyzes: - Budget - Duration - Weather - Interests
(adventure, relaxation, culture, etc.)

It then recommends: - Destinations - Itineraries - Restaurants -
Activities - Estimated trip costs

The system integrates online travel APIs with NLP and Machine Learning
to deliver human-like recommendations and day‑by‑day planning.

------------------------------------------------------------------------

# 🚀 Features & Functional Requirements

## 🏠 Home Page

-   Natural language search (e.g., *Plan a 3-day trip under 25,000 PKR*)
-   AI-powered featured destinations
-   Weather highlights and travel advisories
-   Login / Register options
-   "Plan My Trip" button
-   Real-time suggestions
-   Personalized greetings

------------------------------------------------------------------------

## 👤 User Registration & Profile

Users can: - Sign up with Email or Google - Set travel style - Choose
budget range - Select preferred regions - Specify trip duration

Profile data is used for personalization.

------------------------------------------------------------------------

## 🎯 Destination Recommendation System

Uses Machine Learning: - Content-Based Filtering - Collaborative
Filtering

Data includes: - Cost - Climate - Best seasons - Activities - Safety
ratings - Reviews

Cold-start users receive trending/popular suggestions.

------------------------------------------------------------------------

## 🧠 NLP Query Understanding

Understands queries like: - Plan a 3-day adventure trip near Islamabad -
Honeymoon beach under budget

Extracts: - Intent - Destination - Budget - Duration - Activities

Technologies: - spaCy - BERT - HuggingFace Transformers

------------------------------------------------------------------------

## 🗓 Dynamic Itinerary Generator

Automatically creates optimized schedules based on: - Time constraints -
Distance between attractions - Budget - User interests

Example: Day 1 → Arrival + Hotel + Market\
Day 2 → Hiking + Lake + Dinner\
Day 3 → Shopping + Return

Users can edit plans manually.
